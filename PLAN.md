### 💻 1. Developer & Coding Workflow
*Widget penunjang ritme kerja teknis harian tanpa perlu gonta-ganti window.*

1. **🌿 Git & GitHub Activity Pulse (`🐙`)**
   - **Deskripsi:** Menampilkan status singkat profil GitHub Anda (commit streak hari ini, pending PR review count, atau issue tracker pribadi).
   - **Fitur Kunci:** Notifikasi visual subtle jika ada review request yang tertahan, visualisasi grid contribution mingguan yang minimalis.

2. **⚡ Code Snippet Vault / Scratchpad (`💻`)**
   - **Deskripsi:** Tempat menyimpan potongan command regex, bash script, query SQL, atau code snippet yang sering dipakai berulang kali.
   - **Fitur Kunci:** Syntax highlighting ringan, 1-click copy to clipboard, dan filter tag (`#git`, `#docker`, `#sql`).

3. **⏱️ Timezone & Team World Clock (`🌍`)**
   - **Deskripsi:** Multi-timezone clock ringkas untuk memantau waktu rekan kerja/klien di berbagai belahan dunia (misal: UTC, PST, JST, WIB).
   - **Fitur Kunci:** Indikator status jam kerja (*Online/Offline/Asleep*) dengan bar visual sederhana.

4. **🌐 API / Dev Server Ping Monitor (`📡`)**
   - **Deskripsi:** Widget pemantau kesehatan endpoint lokal/staging (misal: `localhost:3000`, API staging, atau staging DB).
   - **Fitur Kunci:** Indikator status dot (🟢/🔴) dengan interval check hening.

### 🎯 2. Deep Work, Focus & Task Management
*Menjaga fokus harian agar tidak terdistraksi saat membuka tab baru.*

5. **⏳ Countdown & Deadline Tracker (`⏳`)**
   - **Deskripsi:** Countdown visual menuju sprint review, release date, exam, atau project launch.
   - **Fitur Kunci:** Progress bar persentase sisa hari menuju deadline dengan visual *dim glassmorphism*.

6. **🌊 Flow / Ambient Sound Generator (`🎧`)**
   - **Deskripsi:** Built-in ambient noise player langsung di browser untuk membantu deep work tanpa membuka tab Spotify/YouTube.
   - **Fitur Kunci:** Preset audio minimalis (Rain, White Noise, Cafe, Cyberpunk Lo-fi, Binaural Beats 40Hz) dengan volume slider hening.

7. **🛑 Distraction Stopper / Anti-Procrastination Rule (`🛡️`)**
   - **Deskripsi:** Catatan pengingat intensi atau *Anti-Goal* harian (contoh: *"Jangan buka Twitter sebelum 3 task utama selesai"*).
   - **Fitur Kunci:** Tampilan checklist *boundary rules* harian yang bisa di-tick setiap kali Anda berhasil menahan distraksi.

### 🧠 3. Knowledge Management & Note-taking (Obsidian Companion)
*Menjembatani tab browser dengan sistem *second brain* Anda.*

8. **📖 Read Later / Pocket Backlog (`📑`)**
   - **Deskripsi:** Tempat melempar link dokumentasi, artikel tech, tutorial, atau RFC yang ingin dibaca nanti saat waktu santai.
   - **Fitur Kunci:** 1-click simpan tab saat ini, estimasi waktu baca (misal: `5 min read`), dan tombol *Copy URL as Markdown*.

9. **🌱 Daily Learning Log / TIL (Today I Learned) (`🧠`)**
   - **Deskripsi:** Slot 1-2 baris catatan ringkas tentang apa hal baru yang dipelajari atau dipecahkan hari ini (bug fix, konsep baru, tool baru).
   - **Fitur Kunci:** Opsi export langsung format markdown untuk ditempel ke *Daily Notes Obsidian*.

10. **💭 Random Mental Model / Decision Prompt (`🎲`)**
    - **Deskripsi:** Kartu insight acak seputar *problem-solving frameworks* (misal: First Principles, Rubber Ducking, Pareto 80/20, Occam's Razor, Inversion).
    - **Fitur Kunci:** Tombol *Shuffle* untuk trigger ide saat buntu dalam *system design* atau *debugging*.
